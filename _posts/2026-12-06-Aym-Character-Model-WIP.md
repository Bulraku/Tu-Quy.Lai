## Project Overview

This project is a work-in-progress 3D character model of Aym from *Cult of the Lamb*. It was created as part of a semester project where the task was to design assets for a fictional 3D sequel.

Rather than recreating the original character exactly, I chose to reinterpret Aym with design changes that suggest how the character might evolve between the first game and a sequel. The goal is to translate the original 2,5D design language into a stylized 3D character while maintaining the character's recognizable identity.

## Current Status

The model is currently in the high-poly development stage. The main silhouette, head shape, facial features, and core body proportions have been established. The next production phase will focus on retopology, UV mapping, texturing, and final presentation renders.

## Challenges

One of the main challenges was translating a flat, stylized 2D character into a 3D form while keeping the design recognizable. Since Aym is originally designed for a 2,5D game, the model required interpretation rather than direct copying.

Another challenge was deciding which design elements should remain faithful to the original and which could be adjusted to support the fictional sequel concept. The model needed to feel familiar while still showing visual development and change.

Additionally Zbrush proved to have a steep learning curve aswell as unusual issues leading to several crashes.

## Development Process

### Blockout Phase

The project began with a rough blockout to establish the character's proportions, silhouette, and major forms. This stage focused on readability before moving into smaller features.

### Feature Development

After the main body shape was established, the facial features, ears, and character-specific details were developed further. This stage helped define the character's personality and sequel-inspired changes.

![Feature Development]({{ site.baseurl }}/assets/img/WIP_Aym/Feature_Development.png)

### Art Bible Documentation

Development progress is being documented in an Art Bible as part of the semester project. The Art Bible records design decisions, modeling steps, tool usage, and iteration throughout production.

![Art Bible Documentation]({{ site.baseurl }}/assets/img/WIP_Aym/current_state_artbible.png)

### Current Model State

At the current stage, the sculpt has reached a point where the major forms are readable and ready to move toward retopology. The next step will be creating cleaner geometry suitable for UV mapping and texturing.

![Current Model State]({{ site.baseurl }}/assets/img/WIP_Aym/Current_state.png)

## Next Steps

The next phase of this project will focus on preparing the model for a game-ready workflow. This includes retopology, UV mapping, texturing, and final presentation renders.

The finished asset will aim to present Aym as a believable stylized 3D character for a hypothetical sequel while preserving the core identity of the original design.
